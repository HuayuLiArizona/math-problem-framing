# 非数学家可执行的验证方法

前提：用户通常没法逐行检查一个证明，但可以执行检查。好的验证方案要把"相信模型"变成"运行一个检查并看结果"。每个问题挑 2–4 项最有效的，写成具体步骤（带具体参数值和预期结果），不要只写方法名。

## 目录

1. 特例还原
2. 极限与渐近行为
3. 量纲 / 单位
4. 数值对照（模拟、蒙特卡洛、暴力计算）
5. 符号计算
6. 对抗式审稿
7. 一致性与稳健性检查
8. 危险信号清单

---

## 1. 特例还原

把参数设到一个你已经知道答案的情形，看结果是否退化成已知答案。

- 例：多房室模型的结果在只剩一个房室时应退化成单房室公式。
- 例：带阻尼振子的频率公式在阻尼为 0 时应给出 $\omega_0=\sqrt{k/m}$。
- 例：对任意维度 $d$ 的结论，代入 $d=1$ 后自己用纸笔算一遍。

写法："取 [参数值]，公式应当给出 [已知值]；如果不是，说明推导有误。"

## 2. 极限与渐近行为

参数趋于 0 或 ∞ 时，结果的行为应符合直觉或已知物理/生物规律。

- 剂量趋于 0 时浓度应趋于 0；给药间隔趋于 ∞ 时不应有累积。
- 噪声趋于 0 时，随机模型的结果应收敛到确定性模型的结果。
- 样本量趋于 ∞ 时，估计量的方差应趋于 0（若声称一致）。

## 3. 量纲 / 单位

最便宜、最常被忽略的检查。公式两边单位必须一致；$\exp(\cdot)$、$\log(\cdot)$、$\sin(\cdot)$ 的自变量必须无量纲。很多推导错误会直接表现为单位不一致。

## 4. 数值对照

最有说服力的检查：用一种与推导**独立**的方式算出同一个量，比较两者。

- **直接模拟**：数值求解 ODE/PDE（如 `scipy.integrate.solve_ivp`），与闭式解在若干时间点比较。
- **蒙特卡洛**：对期望、概率、方差类结论，抽样估计并给置信区间，看理论值是否落在区间内。
- **暴力计算**：对组合或离散问题，在小规模上穷举。
- **扫参数**：在一个参数网格上比较，而不是只比一个点——很多错误只在部分参数区域出现。

要求模型附上代码时，请它：只用常见库（numpy / scipy / sympy / matplotlib）、固定随机种子、打印理论值与数值值以及相对误差。用户自己运行，不依赖模型报告的运行结果。

## 5. 符号计算

用 sympy（或 Mathematica / Maple）验证关键代数步骤：求导、积分、化简、解方程、级数展开。

```python
import sympy as sp
t, k, D, V = sp.symbols('t k D V', positive=True)
C = D/V*sp.exp(-k*t)
assert sp.simplify(sp.diff(C, t) + k*C) == 0   # 验证 C 满足 dC/dt = -kC
```

适合检查"这个解是否真的满足方程"这类问题——验证一个解往往比求解容易得多。

## 6. 对抗式审稿

把问题陈述和答案交给**另一个模型或新开的对话**，使用 `prompt-templates.md` 中的 T8 审稿模板。要点：

- 明确角色是"找错"，不是"确认"；
- 要求逐步标记"正确 / 有缺口 / 错误"；
- 要求列出答案用了但题目中没有的假设——这是最常见的错误来源；
- 要求核对引用的定理是否存在、条件是否满足。

两个独立模型都认为正确，比一个模型自信地说"正确"可信得多，但仍不等于证明。

## 7. 一致性与稳健性检查

- **换方法重解**：用另一种方法（如换成能量方法、换成数值方法）独立求解，看结果是否一致。
- **改写问题**：用等价但不同的表述再问一次，看结论是否稳定。
- **多次采样**：对同一 prompt 多问几次，结论来回变化说明模型不确定。
- **追问边界**：问"这个结论在什么情况下不成立？"——给不出的话要警惕。

## 8. 危险信号清单

看到以下情况时要提高警惕：

- 结论比预期"好得多"，或推翻了领域内的普遍认识，却没有解释为什么之前没人发现；
- 引用的定理找不到出处，或名字似是而非；
- "显然""易证""不失一般性"出现在关键步骤；
- 推导中途悄悄改变了假设（例如前面说一般分布，后面用了高斯的性质）；
- 只给了特例的证明，却以一般结论陈述；
- 极限交换、求和与积分交换、对未知函数求导时没有任何说明；
- 数值验证只在一个精心挑选的点上做。
