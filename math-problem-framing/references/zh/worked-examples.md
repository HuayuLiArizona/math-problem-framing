# 完整示例：从模糊描述到最终 prompt

三个示例分别来自临床、合成生物学和机器学习。重点看每一步*做了什么选择、为什么*，而不是照抄内容。实际交付时 prompt 会更贴合用户的具体情况。英文版见 `references/en/worked-examples.md`。

---

## 示例 1：漏服药物后多久恢复（临床 / 药代动力学）

**用户原话**："病人每天吃一次某药，偶尔会忘一次。我想知道漏服以后血药浓度要多久才能回到正常水平，还有到底该不该补服。想让 GPT 帮我算，但不知道怎么问。"

**Stage 0**：入口 B（隐约知道是"药代动力学"）；答案形态 = 推导 + 方案比较。

**Stage 1 关键追问**（每个都会改变数学）：
1. 药物大概的半衰期？（决定 $k\tau$，这是唯一真正重要的无量纲数）
2. 口服后吸收很快（1–2 小时内达峰），还是很慢？（决定能否把吸收视为瞬时）
3. "正常水平"指谷浓度不低于某个有效阈值，还是峰浓度不超过某个毒性阈值？
4. 你想比较哪几种补救方式？（不补 / 想起来就补 / 下次加倍）

假设用户答：半衰期约 12 小时，吸收快，关心谷浓度，比较三种方式。

**Stage 2 形式化卡片（精简）**：
- 单房室、一级消除、瞬时吸收（简化，标注）；剂量 $D$，分布容积 $V$，消除速率 $k=\ln 2/t_{1/2}$，给药间隔 $\tau=24\,\text{h}$。
- 线性药动学 → 叠加原理成立（关键假设，标注）。
- 目标：(a) 稳态下在第 0 次给药处漏服后，第 $n$ 个间隔末的谷浓度相对稳态谷浓度的缺口，作为 $n$ 和 $k\tau$ 的函数；(b) 使缺口 $\le\varepsilon$ 的最小 $n$；(c) 三种补救策略下的谷浓度与峰浓度轨迹比较，补服延迟 $\delta\in(0,\tau)$。

**回译要点**："我假设这个药在常用剂量范围内是线性代谢的——即剂量翻倍浓度就翻倍。如果它的代谢会饱和（比如苯妥英），下面的结论就不适用了。我还假设吃下去就立刻进入血液，对吸收很快的药这是合理近似，但会高估补服后的峰值。"

**最终 prompt**：

```markdown
# 任务
在下面的单房室模型下，推导漏服一次对血药浓度影响的闭式表达式，并比较三种补救策略。若某个量没有闭式解，给出精确的隐式表达及其计算方法。
推导之前，先复述问题并列出歧义。

# 背景
临床问题：一种每日一次的口服药（半衰期约 12 小时，吸收快）。疗效取决于谷浓度是否维持在稳态水平附近。形式化陈述以下文为准。

# 记号与定义
- 剂量 $D>0$（mg），分布容积 $V>0$（L），消除速率常数 $k>0$（1/h），给药间隔 $\tau>0$（h）。记 $r=e^{-k\tau}\in(0,1)$。
- 给药时刻 $t_j=j\tau$，$j\in\mathbb Z$（无穷远的过去开始给药，因此漏服前系统处于稳态）。
- 时刻 $s$ 单次推注 (bolus) 后的浓度：$t\ge s$ 时 $C(t)=\frac{D}{V}e^{-k(t-s)}$，此前为 0。

# 假设
A1. 线性药动学 (linear pharmacokinetics)，不同剂量产生的浓度可以叠加 (superposition)。（本质假设）
A2. 瞬时吸收（静脉推注近似）。（简化——请说明改为一级吸收、吸收速率 $k_a$ 时结论如何变化）
A3. 参数不随时间变化。

# 问题
1. $t_0=0$ 的剂量漏服，其余剂量都按时服用。记 $C_{\min,ss}$ 为稳态谷浓度（给药前一刻）。对 $n\ge1$，求 $t=n\tau$ 给药前一刻的谷浓度，以及相对缺口 $\Delta_n=1-C(n\tau^-)/C_{\min,ss}$，表示为只含 $n$ 和 $r$ 的函数。
2. 给定容差 $\varepsilon\in(0,1)$，求使 $\Delta_n\le\varepsilon$ 的最小整数 $n$。
3. 比较三种策略：(S1) 不补服；(S2) 在 $t=\delta$（$0<\delta<\tau$）补服；(S3) 在 $t=\tau$ 服用 $2D$。对每种策略给出谷浓度序列，以及 $t\ge0$ 上的最大峰浓度相对稳态峰浓度 $C_{\max,ss}$ 的比值。

# 范围（不在问什么）
不考虑群体变异，不考虑非线性动力学，不给具体药物的用药建议——只讨论这个模型的数学。

# 交付要求
- 用叠加原理推导；标出 A1、A2 被用到的地方。
- $\Delta_n$、最小 $n$、S1–S3 峰值比的最终公式，各单独一行。
- 一张表：$\tau=24$ h，$t_{1/2}\in\{6, 12, 24, 48\}$ h 时的 $\Delta_1,\Delta_2,\Delta_3$ 和峰值比。

# 自检
- 极限 $k\tau\to\infty$（无累积）：漏服应只影响区间 $[0,\tau)$。
- 单位：确认所有指数都是无量纲的。
- 附一个 Python 脚本：对过去 200 次给药直接求和模拟给药序列，并与 S1–S3 的公式比较。
```

**验证方案**：运行附带脚本比较公式与直接求和；检查 $t_{1/2}=6$ h 时（几乎无累积）漏服的影响应在一天内基本消失；把 prompt 和答案交给另一个模型用审稿模板检查 S3 的峰值计算。

**延伸关键词**：one-compartment model, superposition principle, accumulation ratio, steady-state trough, missed dose simulation.

## 示例 2：自激活基因回路何时出现"开关"行为（合成生物学）

**用户原话**："我构建了一个转录因子能激活自身表达的回路。有些细胞高表达、有些低表达。我想知道理论上什么参数条件下会出现这种两群细胞的情况，好设计改造。"

**Stage 0**：入口 A（不知道该用什么数学）。Stage 3 判断：两群细胞 → 可能是双稳态（确定性），也可能是随机切换或细胞间外在差异。先在交付里点明这三种解释，用户选择先检验双稳态。答案形态 = 推导参数区域。

**Stage 1 关键追问**：
1. 激活是否有协同性（转录因子以二聚体或多聚体起作用）？——双稳态通常需要 Hill 系数 $n>1$
2. 有没有本底泄漏表达？
3. 蛋白主要靠降解还是靠细胞分裂稀释？（决定 $\gamma$）
4. 你能调的是哪个参数（启动子强度、RBS、降解标签）？——这决定该把分岔图画在哪个参数上

**Stage 2 卡片要点**：$\dot x=\alpha_0+\alpha\frac{x^n}{K^n+x^n}-\gamma x$，$x\ge0$ 为蛋白浓度；无量纲化 $u=x/K$、$\tau=\gamma t$ 后剩下 $a_0=\alpha_0/(\gamma K)$、$a=\alpha/(\gamma K)$、$n$ 三个参数。目标：在 $(a,a_0)$ 平面上对每个 $n$ 给出恰有两个稳定平衡点的区域，边界是鞍结分岔曲线。

**回译要点**："这个模型把所有细胞看成一样、浓度连续变化。它能回答'是否存在两个稳定状态'，但回答不了'细胞多久会随机切换一次'——如果你更关心后者，需要随机模型，那是另一个 prompt。"

**最终 prompt**（节选核心部分）：

```markdown
# 任务
精确判断下面的 ODE 何时有两个稳定平衡点（双稳态 (bistability)），并刻画该区域的边界。如果边界没有闭式表达，给出参数化表示。

# 记号与定义
$\dfrac{du}{d\tau}=f(u)=a_0+a\dfrac{u^n}{1+u^n}-u$，$u\ge0$，其中 $a>0$，$a_0\ge0$，Hill 系数 $n\ge1$（实数）。

# 问题
1. 对哪些 $(n,a,a_0)$，$f$ 有三个非负零点且其中两个稳定？（注意 $a_0=0$ 时 $u=0$ 是零点。）证明 $n>1$ 是必要条件。
2. 对固定的 $n$，给出 $(a,a_0)$ 平面上的鞍结分岔 (saddle-node bifurcation) 曲线，用平衡值 $u^*$ 参数化（利用 $f(u^*)=0$、$f'(u^*)=0$）。
3. 求双稳态区域终止处的尖点 (cusp)，作为 $n$ 的函数。

# 范围（不在问什么）
只考虑确定性模型；不求随机切换速率；不考虑空间效应。

# 交付要求
推导过程；最终的区域描述；固定 $a_0$、改变 $a$ 时滞后回线 (hysteresis loop) 的描述。

# 自检
- 确认 $n=1$ 时对所有 $a, a_0$ 都是单稳态。
- 附 Python 代码：取 $n=2$，在 $(a,a_0)$ 网格上数值统计 $f$ 的零点个数，并叠加你给出的解析边界。
```

**延伸关键词**：positive autoregulation, bistability, saddle-node bifurcation, cusp catastrophe, hysteresis, Hill function, （随机方向）chemical master equation, mean first passage time.

## 示例 3：REINFORCE 梯度方差（机器学习）

**用户原话**："我训练离散隐变量模型，用 score function 估计梯度，方差特别大。听说加 baseline 有用，但不知道 baseline 该怎么选、理论上能降多少。"

**Stage 0**：入口 B；答案形态 = 推导（方差表达式与最优 baseline）。

**Stage 1 关键追问**：
1. baseline 是一个常数、每个参数分量一个常数，还是可以依赖输入 $x$？（决定最优解的形式）
2. 是单样本估计还是 $K$ 个样本？（决定是否能用 leave-one-out baseline）
3. 关心的是总方差（迹）还是每个分量？

**Stage 2 卡片要点**：$z\sim p_\theta(z)$（离散），$f(z)$ 不依赖 $\theta$；估计量 $\hat g_b=(f(z)-b)\,\nabla_\theta\log p_\theta(z)$；目标是 $\mathrm{tr}\,\mathrm{Cov}(\hat g_b)$ 关于 $b$ 的最小化；需要区分"$b$ 为标量"和"$b$ 为向量（逐分量）"两个版本。

**最终 prompt**（节选核心部分）：

```markdown
# 任务
推导带 baseline 的 score function（REINFORCE）梯度估计量的方差，求使方差最小的 baseline，并证明无偏性条件。

# 记号与定义
$z\sim p_\theta$，取值于有限集 $\mathcal Z$；$\theta\in\mathbb R^m$；对所有 $z$，$p_\theta(z)>0$ 且关于 $\theta$ 可微。$f:\mathcal Z\to\mathbb R$ 不依赖 $\theta$。记 $s(z)=\nabla_\theta\log p_\theta(z)\in\mathbb R^m$。估计量：$\hat g_b=(f(z)-b)\,s(z)$。

# 问题
1. 证明对任何不依赖 $z$ 的 $b$，$\mathbb E[\hat g_b]=\nabla_\theta\mathbb E[f(z)]$。举例说明 $b$ 依赖 $z$ 时会产生偏差。
2. （标量 $b$）求使 $\mathrm{tr}\,\mathrm{Cov}(\hat g_b)$ 最小的 $b^\star$ 及最小值。
3. （逐分量 $b\in\mathbb R^m$，估计量为 $(f(z)-b_i)s_i(z)$）求最优的 $b_i^\star$。
4. 比较 $b^\star$ 与常用选择 $b=\mathbb E[f(z)]$：何时二者相等？举一个二者差别很大的例子。

# 范围（不在问什么）
只考虑单样本估计量；不讨论重参数化 (reparameterization) 或连续松弛。

# 自检
附 Python 蒙特卡洛检验：$z\sim\mathrm{Bernoulli}(\sigma(\theta))$，$m=1$，自选 $f$，比较 $b\in\{0,\mathbb E f, b^\star\}$ 时的经验方差与你的公式。
```

**延伸关键词**：score function estimator, REINFORCE, control variates, optimal baseline, Rao–Blackwellization, RLOO (leave-one-out baseline).
